# ImperialAI
**Overview:**
This repository contains my capstone project for the Professional Certificate in Machine Learning and Artificial Intelligence at Imperial College London.

The project explores Bayesian optimisation techniques to maximise the performance of a series of black-box functions under limited evaluation budgets.

**Objectives:**
- Implement Bayesian optimisation workflows
- Optimise eight black-box functions
- Compare optimisation performance
- Analyse optimisation progress
- Document findings and lessons learned
